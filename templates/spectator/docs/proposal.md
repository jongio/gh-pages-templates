# Proposal

![Spectator illustration: a document with a highlighted decision path.](/images/page-example.svg)

Project Northstar proposes a single review surface for changes that currently
arrive as disconnected documents, chat threads, and issue comments.

::: plain-language Review surface
A review surface is simply the place where people read a proposal, understand
what changes, and leave feedback.
:::

## The outcome

Reviewers should be able to answer three questions without opening another tool:

1. What decision is being proposed?
2. What will change for users and operators?
3. Where should a concern or correction be recorded?

## Boundaries

| Included | Not included |
| --- | --- |
| Static specification publishing | Real-time collaborative editing |
| Page and selected-text feedback | Embedded comment storage |
| Direct GitHub edits | A custom identity system |
| Flexible Markdown organization | A mandatory specification outline |

## Example requirement

> N-01: A reviewer can select a passage and open a prefilled GitHub issue that
> includes the source page, published page, and quoted selection.

The requirement is an example, not a section Spectator requires.
