# Spectator image handoff

Replace only the images the generated site uses.

- [ ] `favicon.svg`: browser icon, square vector.
- [ ] `logo.svg`: optional navigation identity, square vector.
- [ ] `og.png`: social preview, 1200 by 630 pixels.
- [ ] `hero.svg`: home diagram or product image, 1280 by 640 pixels.
- [ ] `page-example.svg`: example page illustration, 880 by 560 pixels.

Keep the filenames or update every reference in `docs/.vitepress/config.mts` and
the Markdown pages. Every meaningful image needs descriptive alternative text.
